# Lenard Angelo Olajay — Personal Portfolio

Public single-page portfolio for recruiters, hackathon evaluators, and engineering collaborators.

- **URL (Local Preview):** http://127.0.0.1:4173/
- **Stack:** Semantic HTML5, CSS3, Vanilla JavaScript (Progressive Enhancement), Vite.
- **Design Philosophy:** White canvas, clean typography, compact spacing, mobile-first responsiveness, and zero external tracking.

---

## 🚀 Quick Start

### Prerequisites
- Node.js v20+ (developed with v24.14.0)
- npm v10+ (developed with v11.9.0)

### Commands

```bash
# Install development dependencies (Vite)
npm install

# Start local development server (http://127.0.0.1:5173/)
npm run dev

# Run automated tests (12 checks covering assets, markup, security & carousel math)
npm test

# Build production static bundle into dist/
npm run build

# Preview production build locally (http://127.0.0.1:4173/)
npm run preview
```

## 🛠 Maintenance & Content Updates

### 1. Updating the Resume
1. Place your updated resume PDF in `public/assets/documents/Lenard-Olajay-Resume-Updated.pdf`.
2. Run `npm test` and `npm run build` to verify and rebuild the production bundle.

### 2. Adding or Editing Projects
1. Open `index.html` and locate `<section id="builds">`.
2. Edit or add an `<article class="build-card">` block with project title, role, concise summary, tech tags, and repository link.
3. If including a photo, place an optimized WebP in `public/assets/images/` and reference it with `loading="lazy"`.

### 3. Adding or Updating Credentials
1. Open `index.html` and locate `<ul class="credentials-list">`.
2. Add a new `<li>` element with thumbnail image, badge, title, issuer, date, and link to the document.
3. **No JavaScript edits required**: `src/main.js` automatically detects all `.credential-item` elements in the DOM and populates the carousel dynamically.
4. If you have a public Google Drive view link, add it directly to `href` in the `<a class="link-doc">` tag with `target="_blank" rel="noopener noreferrer"`.

## 📋 Ten-Second Comprehension Test Procedure (REQ-015)

To evaluate first-impression readability with real reviewers:

1. Open http://127.0.0.1:4173/ on a desktop or mobile device.
2. Allow an unfamiliar reviewer to view the top section of the screen for exactly 10 seconds.
3. Hide the screen and ask:
   - *What role or discipline does Lenard work in?* (Target: Software Engineering / Developer / Builder)
   - *Can you name one concrete project or contribution he built?* (Target: AqOne maritime SOS, Warang photo map, or Project Tabang disaster response)
   - *Where would you go to contact him or view his full resume?* (Target: Top action buttons / direct links)
4. Target pass rate: at least 2 of 3 reviewers successfully answer all three questions.
5. Record results in `docs/evidence/FEAT-001-verification.md`.
